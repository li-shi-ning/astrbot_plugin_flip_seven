# 翻转七

AstrBot QQ 官方群聊插件，实现桌面卡牌游戏 Flip 7（翻转七）。

## 规则摘要

- 使用官方 94 张牌：
  - 数字牌：0 一张，1 一张，2 两张，……，12 十二张。
  - 行动牌：冰冻 3 张、翻三张 3 张、第二次机会 3 张。
  - 修正牌：+2、+4、+6、+8、+10、x2 各 1 张。
- 每轮结束都会结算并累计积分，不设单局获胜分数线。
- 每轮庄家给每名玩家翻一张初始牌。
- 轮到你时可以 `要牌` 或 `停牌`。
- 翻到重复数字会爆掉，本轮 0 分；持有第二次机会可以抵消一次。
- 集齐 7 张不同数字立即触发翻转七，本轮额外 +15 分并结束本轮。
- 手上只有 0 时不能停牌，必须继续要牌。
- 修正牌不参与数字唯一性判断。
- x2 先把数字总和翻倍，再加其他修正牌。
- 行动牌：
  - 冰冻：目标立即停牌并结算本轮。
  - 翻三张：目标连续翻三张牌。
  - 第二次机会：保留；重复数字时抵消一次。
- 一轮结束时所有玩家停牌或爆掉；每轮结束都会把本轮分数累计到群积分榜。

## 命令

| 命令 | 说明 |
| --- | --- |
| `翻转七菜单` / `翻转七帮助` | 查看规则和命令 |
| `翻转七创建` / `翻转七开局` | 创建房间 |
| `翻转七加入` / `翻转七报名` | 加入房间 |
| `翻转七退出` / `翻转七离开` | 开局前退出 |
| `翻转七开始` / `翻转七发牌` | 房主或管理员开始 |
| `翻转七看` / `翻转七状态` | 查看当前状态 |
| `翻转七要牌` | 当前玩家要牌 |
| `翻转七停牌` | 当前玩家停牌 |
| `翻转七选择 编号` | 行动卡选择目标 |
| `翻转七排行榜` / `翻转七积分` | 查看群内累计积分排行 |
| `翻转七结束` / `翻转七取消` | 结束房间 |
